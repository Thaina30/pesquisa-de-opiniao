Programa em Python que realiza uma pesquisa de satisfação com **50 clientes** da TudoWeb sobre o atendimento prestado.

## 💻 O que o programa faz

Para cada entrevistado, solicita **nome**, **idade** e **opinião**:

`1` = EXCELENTE | `2` = BOM | `3` = RUIM

Ao final, exibe a quantidade de respostas **EXCELENTE** e **RUIM**.

## Conceitos utilizados

- `for` com `range()` para repetir a coleta
- `while` para validar a opinião
- `if / elif / else` para verificar a opinião
- Contadores para as respostas

## ▶️ Como executar

```bash
python pesquisa_tudoweb.py
```
